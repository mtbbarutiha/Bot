# petdate neon logo pack

لوگوهای نئون (سبک ربات + توله سگ‌ها) برای بات و کانال تلگرام.

## برای بات (`@Petdatebot`)

از پوشه `../neon/`:

| فایل | کاربرد |
|------|--------|
| `bot-profile-640.jpg` | عکس پروفایل بات (پیشنهادی) |
| `bot-profile-1024.jpg` | پروفایل کیفیت بالا |
| `bot-welcome-1024.jpg` | تصویر خوش‌آمد `/start` |

این فایل‌ها هم‌اکنون در `packages/bot/assets/` هم کپی شده‌اند و با ری‌استارت بات ست می‌شوند.
